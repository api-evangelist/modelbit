# Modelbit

> Modelbit helps you rapidly deploy and manage ML models with modern MLOps features. Train and register a model in a notebook, deploy a Python function with the modelbit Python SDK, and Modelbit packages the environment and serves the model as a versioned REST inference endpoint (single and batch, sync and async), with a model registry, datasets/feature stores, training jobs, Git-backed deployments, warehouse integration (Snowflake/dbt), and log/alert forwarding.

## API
- REST inference endpoint: `POST https://<your-workspace-url>/v1/<deployment>/latest` (or `/<version>`); body `{"data": <inference-request>}` (single) or `{"data": [[1, req1], [2, req2]]}` (batch)
- Auth: API key in the `Authorization` header (created in Modelbit Settings)
- Async responses, per-request timeouts, and large responses supported
